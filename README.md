# PCCam - USB 카메라 인터벌 촬영 프로그램 (Windows)

USB 카메라(웹캠) 화면을 실시간으로 보고, **정해 둔 시간 간격마다 사진을 계속 찍어 저장**하는 프로그램입니다.

## 주요 기능
- 연결된 USB 카메라 자동 검색 / 선택, 해상도 선택 (640x480 ~ 4K)
- 실시간 미리보기 (FPS 표시)
- **인터벌 촬영**: 초 / 분 / 시간 단위로 간격 지정, 시작·중지 버튼
  - 다음 촬영까지 남은 시간, 저장한 장수 표시
  - 최대 장수 지정 (0 = 무제한)
  - 오래 돌려도 간격이 밀리지 않게 시작 시각 기준으로 계산
  - 디스크 여유 공간이 지정값(MB)보다 적으면 자동 중지
- 수동 촬영 (버튼 또는 **스페이스바**)
- JPG(품질 조절) / PNG 저장, 날짜별 하위 폴더, 사진에 촬영 시각 표시
- 한글 폴더 경로 저장 지원
- 카메라 속성 창 (밝기·노출·초점 등, 카메라 드라이버가 지원하는 경우)
- 설정 자동 저장 (`settings.json`)
- 창 없이 실행하는 명령줄 모드

## 설치 및 실행
1. [Python 3.9 이상](https://www.python.org/downloads/) 설치 — 설치 화면에서 **"Add Python to PATH" 체크**
2. 이 폴더의 `install.bat` 더블클릭 (패키지 설치, 최초 1회)
3. `run.bat` 더블클릭 → 프로그램 실행

### exe 파일로 만들기 (Python 없는 PC에서 사용)
`build_exe.bat` 실행 → `dist\PCCam.exe` 생성. 이 파일만 복사해서 쓰면 됩니다.

## 사용 방법
1. 카메라 선택 → 해상도 선택 → **연결**
2. 저장 폴더 지정 (기본: `사진\PCCam`)
3. 촬영 간격 입력 (예: `30` `초`, `5` `분`)
4. **▶ 인터벌 촬영 시작** — 시작 즉시 1장, 이후 간격마다 저장
5. 다시 누르면 중지

저장 파일 이름 예: `PCCam\2026-11-24\cam_20261124_093000_000.jpg`

## 명령줄(창 없이) 실행
```bat
python main.py --headless -c 0 -i 60 -o D:\타임랩스 -r 1920x1080
```
| 옵션 | 설명 |
|---|---|
| `-c` | 카메라 번호 (0부터) |
| `-i` | 촬영 간격(초) |
| `-o` | 저장 폴더 |
| `-n` | 최대 장수 (0=무제한) |
| `-r` | 해상도 |

`Ctrl+C` 로 종료. 지정하지 않은 값은 `settings.json`(GUI 설정)을 따릅니다.

## 장시간 촬영 팁
- Windows **절전/화면 꺼짐 시 USB 카메라가 멈출 수 있으니** 전원 옵션에서 "절전 모드: 안 함"으로 설정하세요.
- USB 선택적 절전 기능도 끄는 것을 권장합니다 (전원 옵션 → 고급 설정 → USB 설정).
- PC가 잠시 멈춰 촬영이 밀린 경우, 밀린 장은 몰아서 찍지 않고 다음 간격부터 이어서 찍습니다.

## 문제 해결
- **카메라가 안 보임**: 다른 프로그램(줌, 카메라 앱 등)이 카메라를 쓰고 있지 않은지 확인 후 `새로고침`.
- **해상도가 바뀌지 않음**: 카메라가 지원하지 않는 해상도면 가장 가까운 값으로 열립니다 (연결 후 실제 해상도 표시).
- **Windows 개인정보 설정**: 설정 → 개인정보 → 카메라 → "데스크톱 앱이 카메라에 액세스하도록 허용" 켜기.

## 개발
```bash
pip install -r requirements.txt pytest
python -m pytest tests     # 카메라 없이 저장/인터벌 로직 테스트
```
구조: `pccam/camera.py`(카메라), `pccam/capture.py`(저장·인터벌), `pccam/config.py`(설정), `pccam/gui.py`(화면), `main.py`(실행)
